## 🍳 System Features & Architecture

- **Category & Taxonomy Management:** Group culinary preparations across dessert, main courses, appetizers, and custom categories.
- **Structured Recipe Schema:** Stores preparation times, serving sizes, categorized ingredients, and markdown-friendly instructions.
- **RESTful Endpoints & Jinja2 Templates:** Clean server-rendered HTML views styled with modern Bootstrap 5 components and custom CSS.
- **Lightweight Embedded Database:** SQLite integration with automated table initialization for quick deployment.

## 🚀 Quickstart & Execution

```bash
# Clone the repository
git clone https://github.com/ExeDevCentral/Recetario.git
cd Recetario

# Install dependencies
pip install flask

# Launch the application
python3 app.py
```

Open `http://localhost:5000` in your browser.
